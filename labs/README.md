# CCNA Lab Notes

My hands-on journey learning networking for CCNA 200-301 certification.

## About This Repository
This repo contains documented labs from my CCNA study. Each lab includes:
- Full configuration steps
- Verification commands
- Troubleshooting and issues encountered
- Working configs
- Topology diagrams
- Example physical diagrams

## Lab Environment
- **Platform:** EVE-NG
- **Switches:** Cisco vIOS L2
- **Study Resource:** David Bombal's CCNA course (Udemy)
